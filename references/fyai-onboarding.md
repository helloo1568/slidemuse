# 风云AI 生图接入引导

已有可用的宿主生图工具时，继续常规流程，不要求购买或配置其他服务。宿主没有生图能力时，先询问是否接入 API；未经用户授权不购买、配置或切换。风云AI 是赞助方提供的付费选项，并非必选。

1. 用户本人在 [风云AI](https://fyai.uk/) 注册登录，核对当前费用与支持的图片模型，按需创建具备生图权限的密钥。
2. 请用户在自己的本地终端运行下方命令并在隐藏输入提示中提供密钥；**不要在对话、命令行参数或共享文件里填写密钥**。

```sh
python "<skill-dir>/slidemuse.py" generate fyai-setup
```

默认 API 地址为 `https://fyai.uk/v1`、请求使用 `gpt-image-2.6`；以服务商实际支持为准。命令安装共享依赖、写入用户级 `.env` 并向所选服务商发起连通性验证。安装报错时保留可用的宿主路径，不自行换服务，也不要把可能包含凭证的日志直接转发。
