# 原始证据素材与图片版保真

S1 发现科研地图、实验截图、仪器结果、精确数据图时识别；S5 使用这些素材时读取。不把装饰插画、概念草图一律当成需保留的科研证据。

## 在生成前确定处理方式

- **保留原图**：地图点线面、截图、精确图表等证据，默认复制到任务 `assets/`，保留来源和文件哈希，采用等比完整嵌入。生成模型只设计周围页面或留白，不重绘证据区。已有规格要求保留原图时，不能在交付说明中静默降级为“参考生成”。
- **按数据重绘**：有底层数据、需要适配风格的图表，用可靠绘图工具先输出精确独立素材，再作为受保护区域嵌入；仍核对数据和实际几何。地图重新制图应来自原始 GIS 数据和真实制图流程，不能通过生图猜测地理关系。
- **生成示意**：确属概念解释时允许生成，写明示意及含义；不保留可能被误认为测量结果的坐标、比例尺和统计标记。把原证据改成示意涉及内容变更时，按既有授权和变更流程处理。

这仍是图片版路线：最终页面为一张图片，PPT 无需引入原生图层。局部合成遵守宿主工具实际约束；若需要额外授权，先准备独立素材和具体区域方案，再只询问缺失的授权，不重复确认已有授权。

## Page Spec 可执行契约

对需完整嵌入的不透明证据图，在对应元素增加：

```json
"preserve_asset": {
  "file": "assets/network.png",
  "sha256": "此处填写源文件的64位小写SHA256",
  "region": [100, 180, 960, 600]
}
```

`region` 是**实际最终 PNG** 的整数像素 `[x,y,w,h]`，不是 `canvas` 或 `bbox_hint` 坐标。尺寸须与源图等比，允许单像素取整；仅完整缩放，不含裁切、拉伸、重绘或色彩更换。多块受保护区域不重叠。源图须来自独立素材文件，不能把生成页本身声明为源图。带透明通道的源图先在明确底色上制备不透明素材并复核，固定该版本与哈希。

合成时使用经 EXIF 校正的源图 RGB 像素及 Pillow `Image.Resampling.LANCZOS` 缩放。可复用 `preserved_assets.expected_patch(base, declaration)` 获取精确补丁，粘贴到预留矩形；整页保存为不透明 PNG、新文件名。除白底处理等已明确的变换外，预先制作的源图仍需人工核对来源、内容与图例完整性，哈希不能证明来源真实。

新 S5 制作可直接用 [`slidemuse.py produce`](page-production.md) 完成以上合成与恢复，避免临时脚本维护另一份坐标。此入口输出像素尺寸固定为 Page Spec canvas，因此其中的 region 同时位于该输出画布内；旧规格仍按实际最终 PNG 解释。

`validate_page_spec.py --strict` 检查源文件哈希、画幅与区域不重叠；加 `--require-images` 时比较最终 PNG 区域的实际 RGB 像素与按规定缩放的源图。内容不符、裁切或有损重编码将拒绝交付。`build_image_ppt.py` 继承检查，并拒绝对含此契约的页面执行 `--max-width` 或 `--jpeg-quality` 二次压缩。此检查只证明声明区域保留了给定素材，**不证明全页内容、地图本身或数据分析正确**。

旧 Page Spec 没有此字段仍可加载，不追认历史页已保真。新任务中需保留的证据图必须声明；遗漏声明仍需 Agent 在逐页素材清单中发现，脚本不能识别地图。

## 普通交付的四项实查

1. **关键文字**：姓名、专名、数字、日期、单位、表格全部单元格、图例及关键边界。含这些内容的页面建立绑定当前图片的内容观察，运行 `audit_page_content.py --require-complete`；不得复制 Page Spec 充当看图转录。
2. **定量图形**：先清点全页数据视觉，再核对轴、几何与标签。按当前图片分辨率说明像素容差的依据，不为求通过逐次放宽；明显相对误差仍失败。支持的条形图可用 `audit_chart_geometry.py`，其他图型如实记录人工核对范围。
3. **证据素材**：核对本页每个原图的保留/重绘/示意方式及来源；有 `preserve_asset` 时执行像素检查。规格与结果冲突先修复，不能用“AI生成”免责声明代替。
4. **展示可读性**：用实际渲染按目标展示尺寸查看标题、主图、关键标签、正文和来源。地图小字不清时优先裁出独立局部、放大主图或精简非关键标注；不得把简单放大图片称为增加分辨率。

观察记录只写本页实际做过的检查和问题位置，不复制所有页面通用的“已检查”描述。普通验收与完整评分卡继续区分；该契约不额外要求所有任务执行完整评测。
